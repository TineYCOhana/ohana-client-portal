OHANA SIMPLE CLIENT MONITORING PORTAL

HOW TO USE
1. Open index.html in Chrome, Edge, Safari or Firefox.
2. Click Add Client to record an inquiry or booking.
3. Edit a client to update quotation/contract/invoice stages, payments and follow-ups.
4. Open the Payment Monitoring tab to see balances.
5. Use Export CSV for spreadsheet reporting and Backup JSON to save a recoverable copy.
6. Restore JSON imports a saved backup and REPLACES the current browser's records.

IMPORTANT LIMITATIONS
- This version uses browser localStorage, not an online database.
- Records are NOT synchronized across browsers or devices.
- Clearing site data can permanently remove records unless backed up.
- Hosting this file on Vercel does NOT add a shared database or secure login.
- Do not put sensitive personal or financial information into a publicly shared browser instance.
- No automatic email sending, signatures, invoices or payment processing.
- Payments are entered as cumulative totals, not individual transactions.

DEPLOYMENT
You can upload index.html as a static website, but it is best for personal, single-browser use until a backend and authentication are added.
